# Junior Web Designer — Interview & Resume Prep (Codementor Demo)

A sample outline of how I coach mentees preparing for **Junior Web Designer** roles (HTML / CSS / JavaScript portfolio focus). This repo is a teaching demo only — no personal client data.

**Rate context:** typically US$80/hr · 1:1 sessions · flexible for UK / Europe timezones (e.g. Edinburgh / BST)

---

## How I help

### 1. Portfolio review
- Walk through your live sites or GitHub Pages demos with a hiring-manager lens
- Check layout, typography, responsive breakpoints, accessibility basics (contrast, labels, keyboard focus)
- Suggest 2–3 portfolio pieces that best show HTML/CSS craft + light JS interactivity
- Help you write short project blurbs (problem → approach → tech → result)

### 2. Resume & cover letter for web design roles
- Structure a one-page resume that leads with skills and projects, not just coursework
- Translate bootcamp / course work into employer language (responsive layouts, semantic HTML, Figma → code)
- Draft a cover letter pattern: why this company, what you built, what you want to learn next
- See `resume-outline.md` for a reusable template

### 3. Mock interview drills
- **Technical:** explain a layout you built, debug a CSS snippet, walk through a small JS interaction
- **Behavioral:** STAR answers for teamwork, deadlines, feedback, and learning from mistakes
- Timed practice rounds with feedback notes after each answer
- See `interview-questions.md` for a starter question bank

### 4. Sample session plan (60–90 min)

| Block | Time | Focus |
|-------|------|--------|
| Warm-up | 5 min | Goals for this session + any application deadlines |
| Portfolio deep-dive | 20–25 min | One project live review + actionable fixes |
| Resume / cover letter | 15–20 min | Edit one section together (pair-edit) |
| Mock interview | 20–25 min | 2–3 questions, then debrief |
| Next steps | 5 min | Homework checklist before the next session |
