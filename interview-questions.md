# Junior Web Designer — Practice Interview Questions

Generic prompts for mock sessions. Practice out loud; aim for clear structure, not memorized scripts.

---

## Technical

1. Walk me through how you structure a new HTML page from scratch. What goes in `<head>` and why?
2. Explain the difference between Flexbox and CSS Grid. When would you pick each?
3. How do you make a layout work on both desktop and mobile? What breakpoints do you usually start with?
4. A button looks fine in Chrome but is misaligned in Safari. How do you debug it?
5. What does “semantic HTML” mean to you? Give three examples of good vs poor tag choices.
6. How would you add a simple show/hide FAQ accordion with plain JavaScript (no library)?
7. What accessibility checks do you run before shipping a page?
8. Explain `position: relative` vs `absolute` vs `fixed` with a real UI example.
9. How do you organize CSS so a project stays maintainable as it grows?
10. Open DevTools on your portfolio — show me how you’d inspect spacing and fix a padding issue live.

## Portfolio deep-dive
- Why did you choose this color / type scale?
- What would you improve if you had one more week?
- Which part was hardest, and how did you solve it?

## Behavioral (STAR format)
1. Tell me about a time you got design or code feedback you disagreed with. What did you do?
2. Describe a project where you had a tight deadline. How did you prioritize?
3. Give an example of learning a new CSS or JS concept quickly for a project.
4. How do you handle ambiguity when a brief is incomplete?
5. Tell me about collaborating with someone whose skill set differed from yours.

## Closing questions you can ask them
- What does success look like for a junior designer in the first 90 days?
- How does the team review UI work (Figma comments, PRs, live critique)?
- What tech stack and browser support targets should I expect?

---

## Mock drill tips
- Answer in 1–2 minutes; stop and invite follow-ups
- Point at a real project when possible
- If stuck: narrate your thinking (“I’d check X, then Y”)
