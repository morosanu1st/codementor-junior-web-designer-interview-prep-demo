# Junior Web Designer — Resume Outline (Sample)

Use this as a scaffold. Keep to **one page**. Prefer concrete project links over long paragraphs.

---

## Header
- Full name
- City / remote preference · email · LinkedIn · portfolio URL · GitHub

## Summary (2–3 lines)
Aspiring Junior Web Designer with hands-on HTML, CSS, and JavaScript. Comfortable turning designs into responsive pages and iterating from feedback. Looking for a first role focused on front-end craft and collaboration with designers/developers.

## Skills
- **Markup & style:** HTML5, CSS3, Flexbox, Grid, responsive layouts
- **Interactivity:** JavaScript (DOM, events, small UI behaviors)
- **Tools:** VS Code, Git/GitHub, browser DevTools, basic Figma handoff
- **Extras (optional):** accessibility basics, simple animations, Bootstrap / Tailwind

## Projects (2–4 entries)
For each project:
1. **Title** — live link + repo link
2. One-line purpose (what problem it solves)
3. Your role / what you built
4. Tech used
5. One measurable or visible outcome (e.g. “mobile-first; works down to 320px”)

**Example entry shape:**
> **Personal Portfolio Site** — [live] · [repo]  
> Responsive multi-page site showcasing design and code samples. Semantic HTML, CSS Grid layout, light JS for nav and theme toggle. Built to demonstrate clean structure and mobile breakpoints.

## Experience / education
- Course / bootcamp / degree — school, dates, relevant modules
- Any freelance, volunteer, or school web work (even small)

## Optional extras
- Languages, certifications, open-source contributions, design interests

---

## Cover letter skeleton (short)
1. Role + company + one specific reason you applied  
2. One portfolio project that maps to their stack or product  
3. How you work (feedback, deadlines, learning)  
4. Soft close + availability for interview
